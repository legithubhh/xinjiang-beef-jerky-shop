### 状态管理

```javascript
// 使用 localStorage + 事件总线
// [AI-GENERATED] 2026-03-22

class AppState {
    constructor() {
        this.store = {
            cart: [],
            user: null,
            orders: []
        };
        this.listeners = new Set();
    }
    
    // 订阅状态变化
    subscribe(callback) {
        this.listeners.add(callback);
        return () => this.listeners.delete(callback);
    }
    
    // 更新状态
    setState(key, value) {
        this.store[key] = value;
        localStorage.setItem(`beef-${key}`, JSON.stringify(value));
        this.notify();
    }
    
    // 通知所有订阅者
    notify() {
        this.listeners.forEach(cb => cb(this.store));
    }
}
```

## 🔧 后端架构

### API 设计原则

1. **RESTful 风格**
   ```
   GET    /api/products      # 获取产品列表
   GET    /api/products/:id  # 获取产品详情
   POST   /api/orders        # 创建订单
   GET    /api/orders/:id    # 获取订单详情
   ```

2. **统一响应格式**
   ```javascript
   {
     "success": true,
     "data": { ... },
     "message": "操作成功",
     "timestamp": "2026-03-22T10:00:00Z"
   }
   ```

3. **错误处理**
   ```javascript
   {
     "success": false,
     "error": {
       "code": "VALIDATION_ERROR",
       "message": "参数验证失败",
       "details": [ ... ]
     }
   }
   ```

### 中间件链

```
Request → CORS → BodyParser → Auth → RateLimit → Route → Response
```

## 🚀 性能优化

### 前端优化

1. **代码分割**: 按路由懒加载
2. **资源压缩**: CSS/JS 压缩
3. **图片优化**: WebP 格式 + 懒加载
4. **缓存策略**: Service Worker + localStorage

### 后端优化

1. **数据库索引**: 常用查询字段
2. **查询优化**: 避免 N+1 查询
3. **连接池**: 数据库连接复用
4. **异步处理**: 耗时操作异步化

### CDN 策略

```
静态资源 → CDN 边缘节点 → 用户
API 请求 → 源站服务器 → 数据库
```
