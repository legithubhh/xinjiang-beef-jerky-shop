## 📐 核心原则

### 1. 文档优先 (Documentation First)
- **任何功能开发前** 必须先更新相关文档
- **任何代码提交** 必须附带变更说明
- **任何 bug 修复** 必须记录到问题追踪

### 2. 安全至上 (Security First)
- 用户数据加密存储
- 所有输入必须验证
- 敏感操作需要认证
- 定期安全审计

### 3. 人机协作 (Human-AI Collaboration)
- AI 可以生成代码，但人类必须审查
- 所有 AI 生成的代码必须有明确标注
- 重大决策需要人类确认
- 保持代码可读性，便于人类理解

### 4. 持续改进 (Continuous Improvement)
- 每日开发日志
- 每周架构审查
- 每月技术债务清理

## 🔐 安全规范

### 前端安全
- [ ] 所有用户输入必须转义
- [ ] 使用 Content Security Policy (CSP)
- [ ] 防止 XSS 攻击
- [ ] 防止 CSRF 攻击
- [ ] 敏感信息不存储在 localStorage

### 后端安全
- [ ] API 认证和授权
- [ ] 参数验证和清理
- [ ] SQL 注入防护
- [ ] 速率限制
- [ ] 错误信息不泄露敏感数据

### 数据安全
- [ ] 密码加密存储 (bcrypt)
- [ ] 传输加密 (HTTPS)
- [ ] 敏感数据脱敏
- [ ] 定期数据备份

## 📝 开发流程

### 新功能开发

```
1. 需求分析 → docs/LOGS/ 创建开发日志
2. 技术方案 → 更新 docs/ARCHITECTURE.md
3. 实现功能 → 编写代码 + 测试
4. 代码审查 → 人类开发者审查
5. 文档更新 → 更新相关文档
6. 提交合并 → 写入 CHANGELOG.md
```

### AI 协作规范

1. **AI 可以**:
   - 生成代码和测试
   - 编写文档草稿
   - 提出架构建议
   - 进行代码审查

2. **AI 不可以**:
   - 直接部署到生产环境
   - 修改安全配置
   - 访问敏感数据
   - 做出重大架构决策

3. **代码标注**:
   ```javascript
   // [AI-GENERATED] 2026-03-22 - 购物车功能实现
   // [HUMAN-REVIEWED] 2026-03-22 - Jason 审查通过
   ```
